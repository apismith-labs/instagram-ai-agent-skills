# Platform support evidence

This matrix covers the implemented **Instagram Transcript Extractor** only. A host is not declared fully supported merely because one stage has evidence. Codex in the ChatGPT desktop app, Codex CLI, and ChatGPT chat are separate environments. Where existing records do not identify the interface reliably, evidence stays in the general Codex row rather than being assigned to a specific interface. Official setup guides describe possible configuration; they are not project test results.

**States:** **Observed** means directly evidenced in the available execution record; **Reported** means a test was reported but its original trace was not independently reviewed here; **Not independently confirmed** means there is incomplete or ambiguous evidence for that stage or host; **Not tested** means no applicable project test is recorded. These labels describe evidence, not a guarantee for other users.
